# LLM Hallucination Detector

A robust pipeline designed to detect hallucinations in text generated by Large Language Models (LLMs). This system extracts atomic claims from LLM outputs, retrieves external evidence (Wikipedia, Web Search), and verifies the claims using Natural Language Inference (NLI) models.

## 🚀 Features

- **Claim Extraction**: Decomposes complex LLM responses into atomic, independent claims using **Gemini Pro/Flash**.
- **Evidence Retrieval**: Fetches relevant context from **Wikipedia** and **Google Search (via SerpAPI)** to ground the claims.
- **Fact Verification**: Uses a finetuned NLI model (e.g., `roberta-large-mnli`) to classify claims as `Supported`, `Refuted`, or `Not Enough Info` based on the retrieved evidence.
- **Aggregation & Scoring**: meaningful metrics for hallucinations and detailed logs for every step.
- **Dual Interface**:
    - **FastAPI Endpoint** for real-time analysis.
    - **Batch Pipeline** for processing large datasets (CSVs).

## 🛠️ Prerequisites

- Python 3.8+
- [Google Gemini API Key](https://aistudio.google.com/) (for claim extraction)
- [SerpAPI Key](https://serpapi.com/) (optional, for web search fallback)

## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone <repository_url>
   cd llm-hallucination-detector
   ```

2. **Create a virtual environment**
   ```bash
   # Windows
   python -m venv venv
   .\venv\Scripts\activate

   # Linux/Mac
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Environment Setup**
   Create a `.env` file in the root directory (or rename `.env.example`):
   ```bash
   cp .env.example .env
   ```
   
   Update `.env` with your API keys:
   ```ini
   GEMINI_API_KEY="your_gemini_api_key_here"
   SERPAPI_API_KEY="your_serpapi_key_here"
   ```

## 🏃 Usage

### 1. Run the API (Real-time Analysis)
Start the FastAPI server to process individual requests.

```bash
uvicorn main:app --reload
```
- Access the API docs at: `http://127.0.0.1:8000/docs`
- Send a request to `/analyze` with a JSON body: `{"llm_output": "Your text here..."}`

### 2. Run the Batch Pipeline (CSV Processing)
Process a CSV file containing multiple LLM outputs. The script works with single-column CSVs or multi-column files if you specify the column name.

**Standard Usage (uses defaults in config):**
```bash
python pipeline/run_pipeline.py
```

**Custom Usage:**
```bash
# Specify input file and output file
python pipeline/run_pipeline.py -i my_input.csv -o my_results.csv

# Specify text column name (if CSV has multiple columns)
python pipeline/run_pipeline.py -i data.csv -c "llm_response"
```

The script will automatically detect the input column if the CSV has only one column.

## ⚙️ Configuration

You can customize thresholds, models, and retrieval settings in `config/config.py`:

- **Models**: Switch Gemini versions or NLI models (`roberta-large-mnli`).
- **Retrieval**: specific `max_search_results` or Wikipedia language.
- **Verification**: Adjust `contradiction_threshold` or `supportive_entailment_confidence`.
